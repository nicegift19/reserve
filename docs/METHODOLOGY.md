# 계산 기준과 방식 (모델 명세)

`src/model.ts`가 이 문서를 그대로 구현한다. 문서와 코드가 다르면 문서가 기준이며, 변경 시 둘 다 고치고 테스트 기대값도 갱신한다.

- 단위: 금액 **만원**, 기간 **일**, 인원 **명**
- 검증 수준: `[공식]` 공식·학술 자료 확인 / `[2차]` 언론·정리 자료 / `[가정]` 분석자 설정
- 출처 번호 `[n]`은 `docs/SOURCES.md`의 id

---

## 단계 1. 현역 1인 연간 총비용

```
현역총비용 = 봉급월액 × 12 × (1 + 수당률) × (1 + 연금부담률) + 간접비 + 양성비상각
```

| 입력 | 값 | 수준 | 근거 |
|---|---|---|---|
| 대위 8호봉 봉급월액 | 376.38 | [2차] | [7], 공식 대조 [8] |
| 상사 10호봉 봉급월액 | 345.35 | [2차] | [6], 공식 대조 [8] |
| 중사 10호봉 봉급월액 | 291.17 | [2차] | [6], 공식 대조 [8] |
| 수당률 | 0.55 | [가정] | 정근수당·명절휴가비·정액급식비·직급보조비·시간외·가족·주택수당 합산 추정 |
| 연금부담률 | 0.09 | [가정] | 군인연금 국가부담금 단순화 |
| 간접비 | 900 | [가정] | 주거·피복·의료·교육훈련 |
| 양성비상각 | 300 | [가정] | 양성 비용 ÷ 평균 복무기간 |

반올림: 정수(만원).

예시 — 중사 10호봉: `291.17×12 = 3,494.04 → ×1.55 = 5,415.76 → ×1.09 = 5,903.18 → +1,200 = 7,103`

## 단계 2. 현역 기준 비용 (가중평균)

```
현역기준 = round( Σ(현역총비용ₖ × 가중치ₖ) ÷ Σ가중치ₖ , 100만원 단위 )
가중치: 대위 1, 상사 1, 중사 1.3   [가정: 동원사단 대대 간부 구성]
```
예시: `(8,831 + 8,202 + 7,103×1.3) ÷ 3.3 = 7,959.7 → 8,000`

## 단계 3. 현역 연간 유효 근무일

```
225 = 365 − 주말·공휴일 115 − 연가 21 − 교육·파견 등 4      [가정], 효율 1.0
```
당직·비상대기 기여는 미포함(현역에 불리한 방향의 보수적 가정).

## 단계 4. 상비예비군 1인 연간 총비용

```
상비총비용ᵢ = 복무일ᵢ × (일보상비ᵢ + 중식비) + 고정비ᵢ
```

| 입력 | 30일형 | 60일형 | 90일형 | 180일형 | 수준·근거 |
|---|---|---|---|---|---|
| 복무일 | 30 | 60 | 90 | 180 | 사용자 정의 구성 (제도: 단기 30일 이내, 장기 40~180일 [1]) |
| 일보상비 | 12.5 | 15 | 15 | 15 | 장기 15 [공식][1]; 30일형 = 평일10×0.7+휴일15×0.3 = 11.5 + 교통비 1.0 [가정] |
| 중식비 | 0.9 | 0.9 | 0.9 | 0.9 | 예비군 급식비 9,000원 [공식][5] |
| 고정비 | 150 | 150 | 150 | 150 | 선발·신원조사·피복·보험·관리 [가정] |

예시: 180일형 `180×15.9+150 = 3,012`, 30일형 `30×13.4+150 = 552`

## 단계 5. 효율 계수

```
eᵢ = Pᵢ (직무 숙련) × Cᵢ (업무 연속성)
```

| 유형 | 소집 간격 | P | C | e |
|---|---|---|---|---|
| 180일형 | 주 3~4일 | 0.90 | 0.95 | 0.855 |
| 90일형 | 월 7~8일 | 0.90 | 0.88 | 0.792 |
| 60일형 | 월 5일 | 0.90 | 0.82 | 0.738 |
| 30일형 | 월 2~3일 | 0.85 | 0.72 | 0.612 |

근거 [가정]: P는 직책 관련 경험자 우선 선발 [2]. C는 미사용 간격이 길수록 숙련 감쇠가 커지고, 정확성 과업이 더 크게 감쇠한다는 메타분석 [12][13]의 방향을 반영. 수치 자체는 실측 근거 없음 → 부대 실측으로 교체 권장.

## 단계 6. 현역 1명 대체 필요 인원

```
유효근무일ᵢ = 복무일ᵢ × eᵢ
필요인원ᵢ  = 225 ÷ 유효근무일ᵢ
```

## 단계 7. 현역 1명분 비용

```
현역1명분비용ᵢ = 필요인원ᵢ × 상비총비용ᵢ
현역대비비율ᵢ  = 현역1명분비용ᵢ ÷ 현역기준
```

## 단계 8. 최적 조합 탐색 (정수계획, 완전 탐색)

변수: `n = (n30, n60, n90, n180)`, 0 이상 정수

```
최소화   Σ nᵢ × 상비총비용ᵢ
s.t.  ①  Σ nᵢ × 유효근무일ᵢ ≥ 225 × R          (R: 대체할 현역 수)
      ②  Σ nᵢ ≥ W                               (W: 전시 직책 숙달 목표)
      ③  nᵢ ≤ capᵢ                              (확보 가능 인원)
      ④  Σ nᵢ ≤ floor((30 − R) × K)             (K: 현역 1명당 관리 한도) — 소프트 제약
```

절차:
1. n180, n90, n60을 0..cap 범위에서 3중 루프.
2. n30 = max( ceil(남은 유효근무일 ÷ 30일형 유효근무일 − 1e-9), W − (n60+n90+n180), 0 ). n30 > cap30이면 건너뜀.
3. 비교 키 = 비용 + (④ 위반 시 1e12). 키가 가장 작은 조합 선택.
4. 결과 없음 → "조합 없음". 선택 결과가 ④ 위반 → "관리 초과" 표시.

동점 처리: 먼저 찾은 조합 유지(루프 순서 n180 → n90 → n60, 오름차순).

기본값: R=5, W=10, K=1.5, 현역기준=8,000, cap=(40,25,10,5) [가정]
